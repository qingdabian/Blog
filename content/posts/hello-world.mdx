博客终于上线了。这篇文章记录一下从想法到落地的整个过程。

## 技术选型

最初的备选方案很多，最终确定在 **Next.js + TypeScript + Tailwind CSS** 这套组合上，理由很简单：

- Next.js 的 App Router 对静态博客场景支持完善，`generateStaticParams` 可以直接产出全静态页面
- TypeScript 让 front-matter 的类型校验成为可能
- Tailwind CSS 让"多彩卡片风"这类视觉想法能以极低成本实现

## 内容规划

后续计划围绕三个方向持续更新：

1. **技术笔记**：踩坑记录、源码阅读、工具链分享
2. **项目复盘**：从 0 到 1 的完整过程与决策取舍
3. **生活随笔**：读书、观影与一些随想
